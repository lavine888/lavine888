## ♓ 关于我

我本科就读数学与应用数学，目前在香港城市大学攻读计算机科学硕士。我的工作聚焦于两条相互连接的主线：AI 产品与量化系统。

我喜欢把有挑战的想法推进成真正可运行的系统——从零到 Demo 的 AI 产品，到基于 Python 的量化因子研究。过程中，我会把技术判断与产品语境、快速实验、增长思维和清晰的沟通表达结合起来。

| AI 产品 | 量化系统 |
| --- | --- |
| 以人为本的 AI 应用、Agent 与快速产品原型。 | 基于 Python 的因子研究、信号评估与可复现分析流程。 |

无论做产品还是量化研究，我都更重视证据而不是只讲故事：找到真实问题，搭建最小可信系统，用真实用户或可衡量信号验证，再通过迭代持续改进。
